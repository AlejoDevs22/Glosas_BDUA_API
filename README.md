# GLOSA_AFIL_MSS_ORA

Proyecto Node.js para ETL de Glosa (conexiones Oracle y SQL Server).

Pasos rápidos para publicar en GitHub:

1. Inicializar git y hacer commit (ya incluido en el script de inicialización).
2. Crear el repositorio remoto en GitHub (`gh repo create` o crear manualmente en github.com).
3. Empujar cambios: `git push -u origin main`.
